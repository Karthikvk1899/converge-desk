# Security policy

This reference project is not production-qualified. Only the current main branch is maintained.

Use GitHub's private vulnerability reporting feature if enabled, or contact the repository owner through a private channel listed on their GitHub profile. If no private channel is available, open an issue requesting one without revealing exploit details, credentials, or private data. Do not place sensitive reports in public issues.

Include the affected commit, minimal reproduction with synthetic data, expected/actual behavior, and impact. No response-time or remediation SLA is promised. See docs/threat-model.md for scope and known limitations.
